Most of what is here shares one idea: the machine should be checkable. An answer you cannot verify

### Projects

**[plumb](https://github.com/abhinay-hat/plumb)** — Ask a spreadsheet a question in English. plumb
shows the SQL it ran, asks what an ambiguous term means, or tells you the columns cannot answer it.
It does not guess. → [plumb.iamabhinay.com](https://plumb.iamabhinay.com/)

**[DocuMind](https://github.com/abhinay-hat/DocuMind)** — PAN and Aadhaar extraction with
Moondream's vision model behind a FastAPI service. Runs locally, so identity documents never leave
the machine.

**[Voice-Dub](https://github.com/abhinay-hat/Voice-Dub)** — Dubs video into English with each
speaker's own cloned voice, emotional tone preserved and lips resynced. Entirely local, open-source
models throughout.

**[SyncDrop](https://github.com/abhinay-hat/SyncDrop)** — OneDrive for your own hardware. A macOS
menu-bar app that syncs chosen folders to any drive the moment you plug it in. Swift, MIT.

**[continues](https://github.com/abhinay-hat/cli-continues)** — You hit a rate limit mid-debug.
`npx continues` carries the session — history, file changes, working state — into whichever AI
coding tool you switch to. MIT.

**[FinTrack](https://github.com/abhinay-hat/FinTrack)** — Offline personal finance for India.
Multi-account tracking and budgets with no network requirement; the data stays on the phone.
